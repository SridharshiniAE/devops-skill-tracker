# DevOps Skill Tracker

A hands-on DevOps learning portfolio covering Kubernetes, AWS, Terraform, and AI-assisted DevOps.

## Objectives

- Strengthen cloud and infrastructure fundamentals.
- Practise Kubernetes administration and troubleshooting.
- Build infrastructure using Terraform.
- Improve AWS skills.
- Explore AI tools for DevOps.
- Document hands-on labs and projects.

## Learning Areas

| Technology | Focus |
|---|---|
| Kubernetes | Pods, Deployments, Services, Troubleshooting |
| AWS | EC2, S3, IAM, VPC, CloudWatch |
| Terraform | Resources, Modules, State, Infrastructure as Code |
| AI DevOps | AI-assisted troubleshooting and automation |

## Repository Structure

- `tracker/` - Daily study log and weekly reviews
- `kubernetes/` - Notes and hands-on labs
- `aws/` - AWS notes and labs
- `terraform/` - Terraform notes and modules
- `ai-devops/` - AI learning log
- `projects/` - Practical DevOps projects
